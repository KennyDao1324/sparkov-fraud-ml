# Sparkov dataset

- Source: https://www.kaggle.com/datasets/kartik2112/fraud-detection
- Type: fully synthetic credit-card transactions generated with Sparkov
- Licence listed by the distributor: CC0 1.0
- Expected files: `data/raw/fraudTrain.csv` and `data/raw/fraudTest.csv`

The raw files are ignored by Git. The original customer and card identifiers are excluded from model features.
